# Vue frontend QUICK_REF

`apps/web-vue` is the canonical frontend. It uses Vue 3.5 SFCs, Pinia setup stores, TanStack Vue
Query, Ark UI, and Panda CSS generated by the Chakra preset.

## Commands

```sh
pnpm --filter @tgb-resolver/web-vue dev
pnpm --filter @tgb-resolver/web-vue check-types
pnpm --filter @tgb-resolver/web-vue test
pnpm --filter @tgb-resolver/web-vue test:e2e -- --project=chromium
```

## State and styling

- Shared state belongs in Pinia setup stores; component-local state uses Vue refs.
- HTTP and realtime contracts come from `@tgb-resolver/contracts` and `@tgb-resolver/realtime`.
- Ark primitives receive generated Panda slot recipes via `:class`.
- Reusable controls use generated recipes from `@styled-system/recipes`.
- Merge recipe and conditional/atomic styles with `cx(recipe(...), css(...))`.
- Use Panda conditional selectors such as `_hover`, `_disabled`, and `_selected`; avoid scoped
  component CSS for component styling.

## Feature layout

`src/features/control`, `leaderboard`, `assets-manager`, `extensions`, and shared UI are vertical
slices. `src/stores` contains cross-feature Pinia stores, while `src/lib` contains framework-free
domain and transport helpers.

The React implementation in `apps/web` is retained as a legacy behavioral reference during the
migration. See the root `AGENTS.md` for the complete porting and verification rules.
